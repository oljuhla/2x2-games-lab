Games with a mixed equilibrium

In — games neither player has a dominant strategy, and each has an equilibrium where both players randomise. Each player mixes so that the other is indifferent between their two moves, so a player’s mix is set by the other player’s payoffs, not their own.

Ranks are treated as payoffs

The topology only says how each player ranks the four outcomes. Probabilities need cardinal payoffs, so here the ranks 1 to 4 are used as if they were payoffs an equal distance apart. With real payoffs the mixes change: make the crash in Chicken much worse than the other outcomes and each driver swerves more often. Which games have a mixed equilibrium does not change.

The bars give Row’s chance of playing Top and Column’s chance of playing Left. Expected payoffs are what each player averages when both mix, on the same rank scale, and assume each player randomises independently.

Payoff values

Each player’s worst outcome counts 0 and their best counts 1. Slide the two middle ranks to try other payoffs; their order stays the same, so it is still the same game. In Stag Hunt, pushing both towards 0.75 makes hare the safer hunt: the saddle moves towards the stag corner and the hare basin grows.

Pick the mixed equilibrium you want and the payoffs that produce it are filled in. Each player’s mix is set by the other player’s payoffs, so the Top slider changes Column’s payoffs and the Right slider changes Row’s. Of all payoffs giving that mix, the ones closest to the current values are used.

How the table is built

Payoffs are ranks: 4 is a player’s best outcome and 1 the worst. Every game is drawn the same way, with Row’s 4 in the right column and Column’s 4 in the top row, so each game has exactly one place in the table. Its number reads layer, Row’s payoff pattern, then Column’s.

Swapping a player’s two lowest payoffs (1↔2) links games into tiles of four. Swapping the middle payoffs (2↔3) joins tiles into a layer. Swapping the two highest (3↔4) moves a 4 and so changes layer: in layer 1 the two 4s sit in opposite corners, in layer 3 they share a cell, and in layers 2 and 4 they share a row or a column.

Each layer wraps around like a torus, so a tile split across an edge is still one tile. The chart order scrolls the layers so that Prisoner’s Dilemma sits at the centre; “Tiles grouped” puts each tile’s four games side by side instead.

The symmetric games run along the diagonal from bottom left to top right, and every other game has a mirror across it with the players’ roles swapped. Families are named by the payoffs at equilibrium: win-win (4,4), biased (4,3), second best (3,3), unfair (4,2), the Prisoner’s Dilemma family (3,2 or 2,2), and cyclic games with no equilibrium in pure strategies.

The code in brackets is Bruns’ binomial name from “Names for Games” (2015): the symmetric game whose payoff pattern Row has, then Column’s. Samaritan’s Dilemma is HaCh, Harmony × Chicken, and its mirror is ChHa. Symmetric games keep a single code. The codes follow his 2015 names for the symmetric games, so a few differ from this chart’s symbols: Cm is Prisoner’s Delight (his Compromise), Pc is Mixed Harmony (his Peace), As is Assurance and Ha is Harmony, not Hamlet.

Layout and names follow Bryan Bruns’ chart of Robinson and Goforth’s topology (2005). Rapoport–Guyer numbers are read from the chart’s Rapoport, Guyer and Gordon panel. Families, equilibria, dominant strategies and swap neighbours are worked out from each game’s payoffs.
